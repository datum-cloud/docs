[`llms.txt`](https://llmstxt.org/) is a convention for giving AI agents and LLMs a map of a site in plain Markdown. Instead of crawling the docs, an agent fetches one file and gets a list of every page, with a one-line description of each, linked to a clean Markdown version of the page.

Datum publishes three forms of its documentation for agents:

| URL | What it is | Use it when |
| --- | --- | --- |
| [`www.datum.net/docs/llms.txt`](https://www.datum.net/docs/llms.txt) | An index of every docs page, with its title, a one-line description, and a link to its Markdown version. | An agent needs to find the right page for a task. This is the best place to start. |
| [`www.datum.net/docs/llms-full.txt`](https://www.datum.net/docs/llms-full.txt) | The full text of every docs page in one file. | An agent can save and search files, such as a coding agent with a shell. Download it once and search it. At about 740 KB, it's too large for a web fetch tool, so other agents should use `llms.txt`. |
| Any page URL with `.md` added | The Markdown version of one page, such as [`www.datum.net/docs/alb/overview.md`](https://www.datum.net/docs/alb/overview.md). | An agent needs one page without the site's navigation and layout. |

All three are generated from the docs on every deploy, so they always match the live site.

Every Markdown page, `llms.txt`, and `llms-full.txt` starts with a short **Agent Instructions** block that tells an agent where to start and which of these to use.

For an agent-first overview of Datum, start at [agents.datum.net](https://agents.datum.net/): what Datum is, when to use it, pricing, and how to act. Datum also publishes [`datum.net/llms.txt`](https://www.datum.net/llms.txt), an index of the Datum website.

## Use it from an agent

Many agents look for `llms.txt` on their own. To point an agent at it explicitly, add an instruction like the following to your prompt, project instructions, or agent configuration:

```text
Before answering questions about Datum, fetch https://www.datum.net/docs/llms.txt
and read it in full, not as a summary. Use it to find the most specific page for
the task, then fetch that page's .md URL.
```

To give an agent a single page, use the **Copy page** or **Open in Claude** menu at the top of any docs page, or add `.md` to the page's URL.

To let an agent search the docs instead of fetching files, add the hosted [Datum Docs MCP](/agents/datum-mcp#datum-docs-mcp) server, at `https://www.datum.net/docs/mcp`.

## Choose the right tool

`llms.txt` gives an agent knowledge about Datum. To let an agent work with your resources, use one of these as well:

- [Skills](/agents/skills/index) — procedural knowledge an agent loads on demand, such as how to create a load balancer or a DNS record correctly.
- [Datum MCP](/agents/datum-mcp) — live, authenticated access to your Datum resources from an MCP client.
- [`datumctl`](/datumctl/overview) — the CLI, which agents can run directly, with [machine-readable output](/datumctl/output-and-scripting).
