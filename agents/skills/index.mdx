Skills are folders containing a `SKILL.md` file with metadata and step-by-step instructions. Agents discover and load them on demand — no scaffolding, no config files. Datum's official skills cover the most common operations across the [Application Load Balancer](/alb/overview), [gVPC](/galactic-vpc/overview) networks, [DNS](/domain-dns/dns), [domains](/domain-dns/domains), and [metrics export](/operations/metrics-export), with more on the way.

These skills work with any agent that supports Skills, including Claude, Codex, Cursor, Pi, OpenCode, and Mistral Vibe.

## Install

Datum's skills live at **[github.com/datum-cloud/skills](https://github.com/datum-cloud/skills)**. Install for your agent of choice:

<CodeGroup>

```bash Claude Code
claude plugin marketplace add datum-cloud/claude-code-plugins && for p in datum-cloud datum-networking datum-dns datum-compute milo-observe; do claude plugin install "$p@datum-claude-code-plugins"; done
```

```bash npx skills
npx skills add https://github.com/datum-cloud/skills
```

```bash Cursor
# Settings → Rules → Add Rule → Remote Rule (GitHub)
# Repository: datum-cloud/skills
```

</CodeGroup>

In Claude Code, the `datum-cloud` plugin also starts [Datum MCP](/agents/datum-mcp) and the [Datum Docs MCP](/agents/datum-mcp#datum-docs-mcp) server for you, and adds skills to sign in and pick a project, set up a [service account](/projects/service-accounts) for CI, and hand a question to [Patch](/datumctl/ai/assistant). Install the `datum-mcp` binary first; see [Install](/agents/datum-mcp#install). The command also installs the plugins for each Datum product, and is safe to run again. To pick plugins yourself, browse the marketplace with `/plugin` inside Claude Code.

## How skills work alongside Datum MCP and datumctl

Skills tell the agent *how* to think about a Datum resource — the canonical patterns, the right flags, the order of operations. [Datum MCP](/agents/datum-mcp) and `datumctl` are *how* the agent acts. A skill might instruct "always preview HTTPProxy changes with `--dry-run` before applying" — the agent then uses `datumctl` to actually run the command. For open-ended diagnostic questions, an agent can also hand off to [Patch](/datumctl/ai/assistant), Datum's own assistant. See [Agents Overview](/agents/overview) for the full picture.
