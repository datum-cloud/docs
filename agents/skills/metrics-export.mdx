The Metrics Export skill helps agents configure [metrics export](/operations/metrics-export) pipelines in Datum Cloud. It defines named sources, each with a [MetricsQL](https://docs.victoriametrics.com/victoriametrics/metricsql/) selector, and sinks (Prometheus remote write endpoints) that ship project metrics to external observability platforms such as [Grafana Cloud](https://grafana.com/products/cloud/). It teaches agents the manifest structure the API accepts, how to store credentials in a Secret, and how to check each sink's health.

The skill ships in the `milo-observe` Claude Code plugin, alongside skills for querying project logs and reading the status metrics Datum publishes for your resources.

## Install

<CodeGroup>

```bash Claude Code
/plugin marketplace add datum-cloud/claude-code-plugins
/plugin install milo-observe@datum-claude-code-plugins
```

</CodeGroup>

For other agents, copy the [skill folder](https://github.com/milo-os/telemetry/tree/main/claude-plugin/skills/export-metrics) into your agent's skills directory.

<Note>
Once installed, the skill activates automatically when you ask an agent to work with Metrics Export on Datum. No further configuration needed.
</Note>

## Capabilities

- List and describe export policies in a project
- Create metrics export pipelines from YAML manifests
- Select exported metrics with MetricsQL selector expressions, or export everything
- Configure Prometheus remote write endpoints with credentials in a `kubernetes.io/basic-auth` Secret
- Tune batching and retry behavior per sink
- Apply changes idempotently
- Preview changes before applying with `datumctl diff` and `--dry-run=server`
- Check the policy's `Ready` condition and each sink's `Accepted` condition
- Delete export policies safely

## How it relates to other Datum surfaces

- **Product docs:** [Metrics Export](/operations/metrics-export) — the human-facing reference for the export pipeline and ExportPolicy resource
- **Datum MCP:** [Datum MCP](/agents/datum-mcp) — for agents that need live read/write access to export policies during a session
- **`datumctl`:** [datumctl overview](/datumctl/overview) — `get`, `describe`, `apply`, `diff`, `delete` commands the skill teaches agents to use
