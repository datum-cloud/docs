</Warning>

The Client Traffic skill helps agents manage how Datum Cloud edge gateways accept and handle incoming client connections. It covers [Application Load Balancer](/alb/overview) gateway-level settings — TLS termination, mutual TLS (mTLS), HTTP/2 and HTTP/3 (QUIC), connection timeouts and limits, and real client IP detection — all configured by attaching a `ClientTrafficPolicy` to a Gateway listener.

The skill ships in the `datum-networking` Claude Code plugin, alongside procedures for diagnosing a load balancer that isn't serving and for creating networks, using the same diagnosis Datum's own assistant runs.

## Install

<CodeGroup>

```bash Claude Code
/plugin marketplace add datum-cloud/claude-code-plugins
/plugin install datum-networking@datum-claude-code-plugins
```

</CodeGroup>

Installing it also installs the `datum-cloud` base plugin, which runs [Datum MCP](/agents/datum-mcp). For other agents, copy the [skill folder](https://github.com/datum-cloud/network-services-operator/tree/main/claude-plugin/skills/client-traffic) into your agent's skills directory.

<Note>
Once installed, the skill activates automatically when you ask an agent to configure client traffic settings on Datum. No further configuration needed.
</Note>

## Capabilities

- Configure TLS termination: minimum/maximum TLS version, cipher suites, ALPN protocols
- Require and validate client certificates (mutual TLS / mTLS)
- Enable HTTP/2 and HTTP/3 (QUIC) on gateway listeners
- Set client-facing connection timeouts and idle timeouts
- Enforce maximum concurrent connections and per-connection request limits
- Detect real client IP from X-Forwarded-For headers or proxy protocol
- Scope policies to a specific listener via `sectionName`
- List, inspect, and update policies across a project
- Preview changes before applying with `datumctl diff`
- Delete policies safely
- Check permissions before acting

## How it relates to other Datum surfaces

- **Product docs:** [Application Load Balancer](/alb/overview) — the human-facing reference for gateways and edge policies
- **Datum MCP:** [Datum MCP](/agents/datum-mcp) — for agents that need live read/write access to gateway resources during a session
- **`datumctl`:** [datumctl overview](/datumctl/overview) — `get`, `describe`, `apply`, `diff`, `delete` commands the skill teaches agents to use
