The DNS skills help agents work with [DNS](/domain-dns/dns) zones and records in Datum Cloud. They add records, find out why a domain isn't resolving, and move a domain in from another DNS provider. The troubleshooting steps are the same ones [Patch](/datumctl/ai/assistant), Datum's own assistant, follows. Agents read live zone and record status through [Datum MCP](/agents/datum-mcp).

The skills ship in the `datum-dns` Claude Code plugin. Installing it also installs the `datum-cloud` plugin, which runs Datum MCP. Install the `datum-mcp` binary first; see [Install](/agents/datum-mcp#install).

## Install

<CodeGroup>

```bash Claude Code
/plugin marketplace add datum-cloud/claude-code-plugins
/plugin install datum-dns@datum-claude-code-plugins
```

</CodeGroup>

For other agents, copy the [skill folders](https://github.com/datum-cloud/dns-operator/tree/main/claude-plugin/skills) into your agent's skills directory, and connect [Datum MCP](/agents/datum-mcp) so the agent can read zone and record status.

<Note>
Once installed, the skills activate automatically when you ask an agent to work with DNS on Datum. No further configuration needed.
</Note>

## Capabilities

- Find out why a domain isn't resolving, checking domain verification, the zone, registrar delegation and then individual records, in that order
- Name exactly which nameservers are missing at the registrar
- Explain why a record isn't live, or reports `NotOwner` or `Conflict`, and what has to change
- Explain why a record managed by a Gateway, a connector or Datum itself won't stay edited, and where the real change belongs
- Add a record, checking first that no other record set already holds the name, and write it only after you approve it
- Move a domain in from another provider with `/datum-dns:move-zone`. It checks [DNSSEC](/domain-dns/dns#dnssec) before the nameserver cutover, previews the import, and asks before every write
- Run the [`datumctl dns`](/domain-dns/operations) commands to create, list, change, export and delete zones and records

## How it relates to other Datum surfaces

- **Product docs:** [DNS](/domain-dns/dns) — the human-facing reference for DNS zones and records
- **Datum MCP:** [Datum MCP](/agents/datum-mcp) — the live DNS tools the skills use to read zone and record status
- **`datumctl`:** the [`datumctl dns` plugin](/domain-dns/operations) — the commands the skills run for changes you make from a terminal
