---

`datumctl compute destroy` removes a workload, its URLs, and every Instance that it created in every location:

```bash
datumctl compute destroy api
```

Before it deletes anything, the command prints a summary of the number of placements, the locations, the total minimum replicas, and the workload's URLs, and then asks for confirmation. Custom domains attached to a URL stop serving the workload, but Datum keeps the domain resources. To skip the prompt in scripts and CI, pass `-y` or `--yes`:

```bash
datumctl compute destroy api -y
```

<Warning>
  Unlike `datumctl delete` elsewhere in the CLI, `destroy` has no `--dry-run` and there's no `diff` equivalent to preview it. The confirmation prompt is your only checkpoint — read the summary it prints, or check the workload yourself first:

  ```bash
  datumctl compute workloads describe api
  ```
</Warning>
