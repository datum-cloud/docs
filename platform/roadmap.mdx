Datum is still being built. We are building a public cloud with a generous "forever free" tier, and working closely with design partners on managed cloud and BYOC approaches. This page summarizes where each product stands.

## Available today

Our public cloud is opinionated, but powered by key partners. We call these our "house brand" services:

- **[Application Load Balancer](/alb/overview):** an Envoy edge proxy and AI gateway, powered by Tetrate, with a built-in web application firewall.
- **[Connectors](/connectors/overview):** a way to orchestrate connections, starting with QUIC tunnels powered by Iroh.
- **[Domains and DNS](/domain-dns/overview):** domain tracking and verification, plus global authoritative DNS.
- **Essentials:** [metrics export](/operations/metrics-export), [activity logs](/operations/activity-logs), [secrets](/operations/secrets), and team collaboration.

## In preview

- **[Compute](/compute/overview):** isolated Instances that run container images or fast-starting unikernels in Datum locations.
- **[Galactic VPC](/galactic-vpc/overview):** private IPv6 networks for your Instances that span every location they run in, on Datum's SRv6 backbone.

## What we're working on

- **More Connectors:** developer options such as Tailscale tailnets and WireGuard VPNs, and telco options such as AWS Direct Connect, Equinix Fabric, and Megaport onramps.
- **vMMR:** a virtual "meet me room" for interacting with diverse connections.
- **Networking for Instances:** outbound internet access, IPv4 destinations, firewall rules, and private DNS. See [Galactic VPC planned capabilities](/galactic-vpc/limitations-and-roadmap#planned-capabilities).
