title: "Projects"
description: "Projects group the resources you create on Datum within an organization."
---

A Project belongs to an [organization](/organizations/overview) and holds the resources you create, such as load balancers, workloads, networks, and DNS zones. Most `datumctl` commands run against a Project.

## Projects in the Cloud Portal

To see your organization's projects, select your organization in the [Cloud Portal](https://cloud.datum.net), then select **Projects**. Each project shows its ID, which you use with `datumctl`, such as in `datumctl ctx use your-org-id/your-project-id`. To create a project, select **Add project**.

An organization can have up to 10 projects. To request more, contact [support@datum.net](mailto:support@datum.net).
