At Datum, a domain is a resource like any other.

By tracking your domains in one place (regardless of where they are registered or where DNS is hosted), you and your colleagues gain programmatic access to a foundational component of your infrastructure. No more spreadsheets!

## Add a domain

You can add and manage domains through the Datum Cloud portal as well as our programmatic interfaces (MCP and datumctl).

- Add a single domain - Type in the domain name and a resource is created.
- Bulk upload domains - Copy and paste multiple domains or import via a .csv or .txt file.
- [Application Load Balancer](/alb/overview) - Adding a custom hostname to an Application Load Balancer will create a domain resource.

## Verify a domain

Once you add a domain as a resource, you can verify ownership. Verified domains become available for use in other Datum services such as Proxy and DNS Zone Hosting.

<Frame caption="Verify ownership by adding a DNS record">
  ![Domain Verification](/images/domain-verification.png)
</Frame>

Datum gives you two ways to prove ownership, and checks both. Each domain's status holds the exact values to use:

```bash
datumctl get domain DOMAIN_NAME --project your-project-id -o yaml
```

| Method | Status field | What to do |
| --- | --- | --- |
| DNS record | `status.verification.dnsRecord` (`name`, `type`, `content`) | Create the record exactly as given at the domain's DNS provider. |
| HTTP token | `status.verification.httpToken` (`url`, `body`) | Serve `body` at `url`, over plain HTTP, from the domain itself. |

Use the DNS record unless you can't change the domain's DNS. The HTTP token only works when the domain already serves your own content: a domain that is parked at its registrar returns the registrar's page, so the token check fails.

Datum retries verification on its own, and `status.verification.nextVerificationAttempt` shows when. For records that don't seem to take effect, see [Prove you own the domain](/alb/operations/custom-domains#prove-you-own-the-domain).

## Moving DNS hosting to Datum

A domain's registration details include its DNSSEC status as reported by the registry. Datum DNS doesn't currently support DNSSEC. If DNSSEC is on for a domain, turn it off before you point the domain at Datum's nameservers. See [DNSSEC](/domain-dns/dns#dnssec) for the steps.
