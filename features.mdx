## Public Cloud

Our public cloud is opinionated, but powered by key partners. We call these our "house brand" services:

- **Deliver -** An Envoy edge proxy and AI gateway, powered by Tetrate.
- **Build**
- **Connect** - A way to orchestrate connections, starting with QUIC tunnels (powered by Iroh). Planned connections include developer options (e.g. Tailscale Tailnets, Wireguard VPNs) and telco options (AWS Direct Connect, Equinix Fabric, Megaport Onramps, etc).
-  **Essentials** - DNS, domains, metrics export, activity logs, collaboration, etc.

## Roadmap

We're currently working on the following major features:

- **UFOs** - Millisecond cold-start, isolated compute that scales to zero, powered by Unikraft. UFO stands for Unikernel Function Offload, but it's really just a fun name for a futuristic "workers" feature.
- **Galactic VPC** - Virtual private backbones that span anywhere, powered by SRv6.
- **vMMR** - A virtual "meet me room" for interacting with diverse connections.

The best place to track our roadmap is via our [website or milestones](https://www.datum.net/roadmap/). To add or suggest features, please visit our [GitHub discussions](https://github.com/orgs/datum-cloud/discussions/categories/feature-requests) page!
