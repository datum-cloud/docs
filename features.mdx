## Public Cloud

The quickest way to access our value is with our public cloud. Features are organized into the following few categories: 

- **Deliver -** Safely interact with the internet, including with DDoS and WAF protection.
- **Build -** Bring intelligence to the edge of the network with workloads,
- **Connect** - Deploy virtual private backbones and orchestrate secure connections.  
-       **Essentials** - DNS, domains, metrics export, activity logs, collaboration, etc.

## Dedicated Cloud

For scaling companies, we offer three flavors of dedicated infrastructure:

- **Connected Metal** - Bare metal as a service (GPU/CPU) with Datum-provided server CAPEX.
- **Connected Colo** - Automated colocation & network, with customer-provided server CAPEX.
- Network PoPs - Optimized network hubs in key global markets.
