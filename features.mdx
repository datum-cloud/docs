## Public Cloud

The quickest way to access our value is through our public cloud. Features are organized into the following categories: 

- **Deliver -** Safely interact with the internet, including routing, DDoS, and WAF protection.
- **Build -** Bring intelligence to the edge with low latency compute and storage.
- **Connect** - Deploy virtual private backbones and orchestrate secure connections.  
-       **Essentials** - DNS, domains, metrics export, activity logs, collaboration, etc.

## Dedicated Cloud

For scaling companies, we offer three flavors of dedicated infrastructure:

- **Connected Metal** - Bare metal as a service (GPU/CPU) with Datum-provided server CAPEX.
- **Connected Colo** - Automated colocation & network, with customer-provided server CAPEX.
- **Network PoPs** - Optimized network hubs in key global markets.

- **Compute** - Isolated Instances that run container images or fast-starting unikernels in Datum locations, now in preview. For more information, see [Compute](/compute/overview).
- **Galactic VPC** - Virtual private backbones that span anywhere, powered by SRv6.
- **vMMR** - A virtual "meet me room" for interacting with diverse connections.
